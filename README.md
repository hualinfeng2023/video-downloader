# Video Downloader

一个本地运行的流媒体视频下载工具，前端提供粘贴链接、识别视频、选择保存方式、查看下载进度等主流程；后端使用 `yt-dlp` 和 `ffmpeg` 处理 YouTube、Bilibili 等平台的视频解析与下载。

## 启动

```powershell
python server.py
```

启动后打开：

```text
http://127.0.0.1:8787
```

下载文件默认保存到项目内的 `downloads` 文件夹，也可以在界面里填写其他目录。

## 下载组件

本工具会优先使用项目内 `.venv\Scripts\yt-dlp.exe`，并使用项目内带 MP3 编码能力的 ffmpeg。首次配置或更新下载组件：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -U -r requirements.txt
```

## 功能

- 自动识别 YouTube、Bilibili、Douyin、Vimeo 以及 yt-dlp 支持的其他站点
- 识别标题、封面、作者、时长和可用清晰度
- 支持最佳画质、常用 MP4 清晰度、仅音频 MP3，并显示预计文件大小
- 支持合集下载和字幕保存
- 支持下载完成后用 ffmpeg 对指定矩形区域进行去水印处理
- 支持读取 Chrome、Edge、Firefox 的登录状态，用于处理会员、年龄限制或平台 403
- 下载队列显示进度、速度、剩余时间、失败原因和取消按钮
- V1.1 增加智能引导：下载前提示高风险平台，识别或下载失败时给出原因、处理步骤和可点击的设置入口

## 常见失败处理

### 403 Forbidden 或需要登录

1. 先在 Chrome、Edge 或 Firefox 打开对应平台并登录账号。
2. 回到本工具，勾选“使用浏览器登录状态”。
3. 选择刚才登录的平台浏览器，再重新识别或下载。
4. 如果仍失败，更新项目内下载组件。

### Bilibili 412 或风控失败

1. 先更新项目内下载组件。
2. 确认浏览器能正常打开该 Bilibili 页面。
3. 如果仍失败，启用浏览器登录状态后重试。

### 缺少 yt-dlp 或 ffmpeg

按下面命令安装或更新下载组件，然后重启本工具：

```powershell
.\.venv\Scripts\python.exe -m pip install -U -r requirements.txt
```

### 无法读取浏览器登录状态

1. 确认所选浏览器已登录对应平台。
2. 关闭该浏览器后重试。
3. 仍失败时，切换 Chrome、Edge 或 Firefox 中另一个已登录的浏览器。

### 保存位置不可用

检查“保存位置”是否可写。建议先换到项目内 `downloads`、桌面或系统下载文件夹。

### 去水印区域不准确

去水印会在下载完成后对指定矩形区域进行模糊填充。先在界面勾选“启用去水印”，再按水印左上角填写 X/Y，并填写宽高；如果处理后位置不准，请调整区域后重新下载。

### 网络超时

先确认浏览器能正常打开视频页面，再重新识别或下载。公开视频可以先不启用登录状态，减少浏览器 cookies 读取失败的干扰。
